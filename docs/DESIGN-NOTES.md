# StudioSpace — design notes

## Direction

A working studio marketplace with an independent creative identity: ink, off-white, lime, editorial typography, and photography of real production work. The layout gives browsing and booking equal weight with the visual identity.

## Design decisions

1. A search form in the hero sends the selected category and location to Explore. It does not show a nonfunctional date filter.
2. The three-slide hero uses local photographs and keyboard-accessible controls.
3. Studio cards prioritise the image, location, title, and hourly price. New listings show “New” rather than invented ratings.
4. Photographic categories visually distinguish photography, film, podcasts, music, and workshops.
5. The host section explains information that is actually available before a booking request.
6. Booking totals distinguish the hourly rate and security deposit. Reservations visibly start Pending.
7. A FAQ answers actual booking and hosting questions.
8. A larger footer wordmark and consistent local fonts establish the visual identity across the app.
9. Light and dark themes use the same spacing, hierarchy, and controls.
10. Responsive checks include 320px, 390px, 768px, and desktop viewports.
